# GrainCast

GrainCast is a wheat-planning dashboard with a 7-day forecast section, an Australian weather-station map, and a historical comparison chart.

## Included

- Top navigation links for `Predictions`, `Map`, and `Historical Data`
- Clear selection prompt for primary location and wheat type
- Prominent recommendation card for the 7-day prediction
- Weather symbols in the prediction cards
- Temperature shown with `°C`
- Australian station map with hover details
- Primary location in green and up to two secondary locations in blue and red
- Historical comparison chart with hover tooltips
- Historical start and end date selectors
- Temperature filter for `min`, `max`, or `min & max`
